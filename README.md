# 🧠 Psixologik va Kognitiv Baholash Platformasi Telegram Boti (@psixologikIIBbot)

Ushbu Telegram bot Ichki Ishlar Organlari (IIB/IIV) va psixologik baholash tizimi uchun mo'ljallangan bo'lib, quyidagi 3 ta ketma-ket bosqichni o'z ichiga oladi:

1. **1-Bosqich (Mantiq):** 5 ta mantiqiy savol (5 daqiqa, kamida 2 ta to'g'ri javob)
2. **2-Bosqich (Matritsa / Rasmlar):** 5 ta fazoviy va abstrakt rasm savollari (5 daqiqa, kamida 2 ta to'g'ri javob)
3. **3-Bosqich (Psixologiya):** 86 ta psixologik savol (45 daqiqa, 1-qismdan kamida 4 ta, 2-qismdan kamida 40 ta to'g'ri javob)

---

## 💻 Mahalliy ishga tushirish

1. Qaramliklarni o'rnating:
```bash
pip install -r requirements.txt
```

2. `.env` faylini yarating va bot tokenini kiriting:
```env
BOT_TOKEN=sizning_bot_tokeningiz
```

3. Botni ishga tushiring:
```bash
python main.py
```

---
